# Investment Platform Backend

## Overview
Backend API built with Express.js and MongoDB for an investment platform.

## Features
- User Registration
- Login & JWT Authentication
- Referral System
- Investment Management
- Wallet
- Daily ROI Distribution (In Progress)
- Referral Income

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Bcrypt
- Zod

## Installation

npm install

Create a .env file:

PORT=
MONGO_URI=
JWT_SECRET=

Run:

npm run dev
